# Project Gotchas — General
# Last reviewed: 2026-10-20
# Always loaded: one line per trap Claude repeated in this repo. Entries are proposed by [R19 Project Gotcha Capture] or added by hand.

- context-leak: Never Read a sub-agent's `*.output` file — tool noise floods the main context. Judge the summary against the check written before dispatch, not its confidence; re-read every cited file:line before acting. Contract: `src/superclaude/core/rules/RULES_DELEGATION.md`
- compaction-drift: In a long session, rules read at session start fade after auto-compaction; when behavior drifts from a rule, re-read the rule file instead of relying on the compacted summary.
- rule-tag-vs-concept: To count where a rule is cited, grep its exact tag (e.g., \bR18\b), not its concept word: "verification" matches prose all over the tree, the tag matches only citations.
- find-all-copies-first: Before editing a file that may exist in more than one copy (generated artifact, vendored file, the installed copy under `.claude/superclaude/`), grep its basename across the repo, confirm the copy count, and edit the source copy.
- grep-longline-blindspot: Grep `content` mode hides lines of ~460+ chars (`N:[Omitted long matching line]`; older CC: no match). `description:` lines are this shape — a content-mode miss is NOT evidence of absence; sweep with `files_with_matches`. Repro (ASCII, 2026-10-14): `src/superclaude/agents/verifier.md:3`
- windows-make-sync-broken: On Windows, `make sync-*` fails with os error 5 only when `.venv` holds a `lib64` symlink (made by Linux/WSL uv); a Windows-native venv syncs fine (P8 W5). Rebuild as in AGENTS.md Tests, or run `superclaude doctor --scope <s>` then `superclaude install --force --scope <s>`.
- uv-lock-local-only: `uv.lock` is gitignored. Locally the next `uv run` re-syncs to it and silently reverts a `uv pip install --upgrade` ("Uninstalled N packages"); upgrade with `uv lock --upgrade`. CI resolves fresh (`uv pip install --system -e ".[dev]"`), so a new ruff release reaches CI regardless of the lock.
- account-sync-into-config-dir: A scratch `CLAUDE_CONFIG_DIR` with only `.credentials.json` is not clean: claude.ai syncs account skills (first session) and plugins (usually from the second) into it; connectors load too. Add `--setting-sources project,local` + `ENABLE_CLAUDEAI_MCP_SERVERS=false`.
- lint-upgrade-attribution: Lint or type errors arriving with a dependency upgrade: re-run the old tool (`uvx ruff@<old> check src/ tests/`, `uvx mypy@<old> src`) to separate new errors from old. CI gates (test.yml): `ruff check`, `ruff format --check` on src/ tests/, `mypy src`; `make lint` is `ruff check .` only.
- stale-number-copies: A count copied into an always-loaded doc (CLAUDE.md, AGENTS.md, auto-memory) goes stale. Cite the source, never the number: version → `pyproject.toml`; counts → `02_component_and_delivery_map.md` §1; pass count → none, `test_version_consistency.py` forbids one; volatile totals → run the tool
- venv-inherited-by-worktree: In a second checkout with the main `.venv` active, `uv pip install -e .` installs into the main venv (`$VIRTUAL_ENV`). There: `unset VIRTUAL_ENV`, pass `--python <checkout>/.venv/Scripts/python.exe`, check `superclaude.__file__`. Repair main: `--no-deps --python .venv/Scripts/python.exe`.
- sync-scope-creates: `superclaude install --force --scope <s>` (and `make sync-user`) creates an install where none exists, not "refresh if present" — 2026-10-03 a user-scope sync on a local-only machine wrote SC import and hooks into `~/.claude/`, enabling SC everywhere. Check first: `superclaude doctor --scope <s>`
- gitignore-unanchored-dir: A `.gitignore` dir rule without a leading `/` hides that name at any depth: a new or generated dir drops out of `git add`; tests pass on disk, a fresh clone fails. Anchor root-only rules (`/skills/`); dir missing from `git status` → `git check-ignore -v <file>`. Hit 2026-10-05, 10-08
- size-target-no-collateral-cut: A doc over the 25,000-byte target: tighten only the text being added, or split the file; never cut or reword content the request did not touch. Rule: `src/superclaude/core/rules/RULES_DOCS.md` Size
- generated-regex-escapes: A `python -` script's non-raw string turns `\b` into a backspace and `\n` into a newline in what it writes (code, YAML, docs). Text holding a backslash goes through Edit; then `grep -c $'\x08'`. Hit 2026-10-14 twice, 2026-10-21 three times with this entry loaded
- plant-on-a-copy: Planting a violation to prove a guard, then `git checkout -- <file>` to undo it, also discards that file's uncommitted edits (2026-10-21). Plant only in a file with no uncommitted changes, or undo from a copy taken first
- plan-docs-on-branch: A feature plan (`docs/features/<slug>/`) is committed on a `docs/*`, `feature/*` or `fix/*` branch, never onto master; master's direct commits are session memory and `docs/plans/remaining-work-*`. A same-session master commit is no precedent. Source: owner decision 2026-10-21, not AGENTS.md (its Git Workflow names branches only); verification reports committed to master before that date predate it
- security-review-scope: No web surface here: a security review skips web-vuln scans and checks prompt injection via shipped XML/markdown, install-path traversal and hook command injection; installer writes to `~/.claude/` are by design. From the retired security-engineer agent
