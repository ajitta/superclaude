A content framework for Claude Code

The CLI copies framework files into Claude Code's content directories. Claude Code reads them at session start; the framework does not run a proxy or daemon.

Workflows you can invoke

Use /sc:brainstorm, /sc:plan, /sc:implement, and /sc:review across the development cycle.

Specialized agents and modes

Agent definitions and behavioral modes supply task-specific instructions when Claude Code loads the installed content.

Hook-enforced rules

Hooks help preserve workflow rules across sessions and tool calls while the installer merges with existing hook settings.

Optional integrations

The core works without MCP servers. Add supported integrations separately when a task needs them.

Install the CLI and content

Clone this repository, install the CLI with uv via make deploy, then install the framework content. Restart Claude Code after installation.

Full installation and scope options ↗ 
git clone https://github.com/ajitta/superclaude.git
cd superclaude
make deploy
superclaude install --scope user

Choose --scope project for a committed team install or --scope local for personal files inside a project.

Try a command

After restarting Claude Code, begin with a specific task or use /sc:help to see the available commands.

/sc:brainstorm

Explore an underspecified request.

/sc:plan

Turn a task into an implementation plan.

/sc:implement

Work through the implementation.

/sc:review

Review code, a plan, or a design.
