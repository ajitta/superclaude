## 3. Shipped-names history (Q10 keystone guard input)

`tests/fixtures/shipped_names_history.json`, generated by `scripts/gen_shipped_names.py` (the audit harness copy, moved into the repo in P5 and run on HEAD; it adds `serena-hooks.json` and the SKILL.md digests of retired skills) from master's first-parent history with merges diffed against their first parent (`git log --first-parent --diff-merges=first-parent master`), refusing a shallow clone. It records every agent and output-style `.md` name, every skill directory, every hook event and every (event, entry point, subcommand), each with the first and last first-parent revision that had it, plus inline commands verbatim. Since the W-1 verify (X-4, [06b](./06b-verify-w1.md)) it reads every commit reachable from the revision, both parents of a merge (`git log --full-history`): the first-parent walk missed 5 SKILL.md revisions and one hook identity.

E0 read `SuperClaude/Agents` (v4.0.3–v4.1.5) and `superclaude/agents` (v4.1.6); its only names not shipped now are `deep-research-agent.md` and `pm-agent.md`, which the src history already holds.
