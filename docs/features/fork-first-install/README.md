# 포크 우선 설치 가이드

README.md와 Pages(`docs/index.html`)의 설치 안내를 1. Quick install(릴리스 그대로) → 2. Clone install(로컬 clone으로 자기 사본) → 3. Fork install(그 사본을 자기 GitHub 포크에, 추천) 순서로 둔다. 기여자(contributor) 안내는 없애고, `/goal` 앞에 `/btw`로 다음 스텝을 묻는 팁을 넣는다. (처음엔 포크를 맨 앞에 두었으나 사용자 피드백으로 Phase 3에서 재구성)

계기 (2026-10-12, 사용자): "나의 추천 가이드는 포크해서 자신만의 프레임워크로 커스텀하는 거였다. contributors는 의미 없다. 아무도 없으니"
