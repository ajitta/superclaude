# 포크 우선 설치 가이드

README.md와 Pages(`docs/index.html`)의 설치 안내에서 "포크해서 자신만의 프레임워크로 커스텀"을 추천 경로로 맨 앞에 둔다. 릴리스를 그대로 쓰는 Quick Install은 두 번째 경로로 남긴다. 기여자(contributor) 안내는 없앤다.

계기 (2026-10-12, 사용자): "나의 추천 가이드는 포크해서 자신만의 프레임워크로 커스텀하는 거였다. contributors는 의미 없다. 아무도 없으니"
