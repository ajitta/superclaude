# `/sc:intent` 커맨드

분석이 시작되기 전에 요청을 요청자의 말 그대로 다섯 항목(문제, 원하는 결과, 영향 대상과 시스템, 제약, 미결 질문)으로 한 번 기록해 `docs/features/<slug>/00-intent.md`에 커밋하는 커맨드. brainstorm·review·reflect가 이 파일을 의도의 원본으로 읽는다. 출처는 Anthropic AI-Native SDLC Playbook Stage 1 "Capture as intent.md"이며, 2026-10-07 세션에서 "brainstorm과 intent는 다르다"는 판단으로 별도 커맨드로 결정했다.
