목표 모델은 `--model opus55`로 지정된 'claude-opus-5-5'이고, 표에서는 Opus 열을 적용했습니다. 대상 표면은 `--target cc`이며, 프롬프트는 인자로 받은 인라인 텍스트를 썼습니다. 참조 문서 `model-migration.md`에는 `## Migrating to Claude Opus 5.5` 섹션이 없어서 대신 `## Migrating to Claude Opus 5`의 `### Behavioral shifts (prompt-tunable)` 부분(L1034–1152)을 읽고 적용했습니다.

### 다시 쓴 프롬프트

```
슬로우브루 광고 카피를 써 주세요. 인스타그램 피드 광고와 지하철 스크린도어 광고에 쓸 초안이고, 용도는 [FILL: 예 — 내부 시안 회의에서 방향을 고를 후보 / 대행사 브리프 첨부 / A/B 테스트 소재]입니다.

[자료]
- 제품: 슬로우브루 — 12시간 저온 추출 콜드브루 원액 파우치. 1팩으로 4잔.
- 음용법: [FILL: 1잔 만드는 방법과 걸리는 시간 — 예: 물·우유에 섞기, 얼음 여부]
- 타깃: 출근 전 5분이 아까운 30대 직장인.
- 경쟁: 편의점 RTD 커피, 캡슐 머신.
- 강점: 산미 낮고 쓴맛 적음, 상온 6개월 보관, 잔당 900원.
- 브랜드 톤: [FILL: 예 — 담백한지, 위트 있는지, 프리미엄인지 / 피할 말투]
- 필수 요소와 금지 표현: [FILL: 브랜드명·가격 노출 여부, 법무 검토 기준, 금지어]

두 채널은 카피를 읽는 상황이 다릅니다.
- 인스타그램 피드: 스크롤하다 멈춘 사람이 이미지 위 헤드라인과 캡션 첫 줄을 봅니다. 헤드라인, 캡션 본문, CTA를 한 세트로 써 주세요. [FILL: 정해진 이미지·소재 방향이 있으면 적기]
- 지하철 스크린도어: 열차를 기다리거나 지나가는 사람이 한눈에 읽고 지나갑니다. 메인 카피 한 줄에, 필요하면 짧은 서브 카피를 붙여 주세요. [FILL: 게재 규격과 글자 수 제한]

수치와 비교는 위 자료에 있는 것만 씁니다. 경쟁 제품의 가격처럼 자료에 없는 사실은 카피에 넣지 말아 주세요. 넣으면 좋겠다 싶은 정보가 있으면 카피와 따로 적어 주세요. [FILL: 경쟁 제품 가격 같은 비교 근거가 있으면 추가]

채널마다 [FILL: 채널당 안 개수]개 안을 써 주세요. 응답은 카피 위주로 하고, 설명은 짧게 해 주세요.
```

### 변경 내역

**삭제: 0건.** 프롬프트를 제거 대상 목록 전체에 대조했지만 걸린 항목이 없습니다. 사고 주문, 강조어 남발, 전문가 페르소나, 숫자 상한, 선입견 주입, 자기검증 문구 모두 없었습니다.

**추가와 그 출처**
- **"카피라이트"를 "광고 카피"로 바꿈**: 출처는 사용자 요청입니다. 카피라이트는 저작권(copyright)이라는 뜻이고, 채널과 타깃을 준 맥락을 보면 원하는 결과물은 광고 카피입니다.
- **채널별 읽는 상황과 결과물 구성**: 출처는 사용자가 지정한 두 채널입니다. 글자 수를 숫자로 제한하는 대신 누가 어떤 상황에서 읽는지로 적었고, 실제 규격은 `[FILL]`로 남겼습니다.
- **자료에 없는 수치나 비교를 쓰지 말라는 조건**: 출처는 사용자 자료입니다. 경쟁 제품 이름만 있고 가격은 없기 때문에, 이 조건이 없으면 "편의점 커피 2,000원" 같은 숫자를 지어낼 위험이 있습니다.
- **"설명은 짧게"**: 출처는 참조 문서의 Opus 5 섹션입니다. Opus 5는 기본 응답이 길고, 짧게 하라는 지시 한 줄로 응답 길이가 약 20% 줄었다고 합니다. Opus 5.5에도 같은 경향을 적용했습니다.
- **요청을 한 턴에 모두 담는 구성**: 출처는 같은 섹션의 체크리스트 항목 "complete task spec up front in one turn"입니다.

**의도적으로 넣지 않은 것**
- 범위 제한, 끝까지 완료하라는 지시, 하위 에이전트 사용 제한: `--target cc`에서는 하네스가 이미 넣어 주므로 제외했습니다.
- 검증 지시: Opus 계열에서는 검증 지시가 과잉 검증을 부르기 때문에 넣지 않았습니다.
- 해시태그, 비주얼 방향, 카피 선택 근거: 출처가 없어서 넣지 않았습니다.

### 채워야 할 빈칸
1. **용도**: 시안 후보로 쓸지, 브리프에 첨부할지, A/B 테스트 소재로 쓸지
2. **음용법과 소요 시간**: "출근 전 5분"이라는 소구점을 뒷받침하려면 가장 중요한 정보입니다
3. **브랜드 톤과 피할 말투**
4. **필수 요소와 금지 표현**: 법무 검토 기준도 포함합니다
5. **인스타그램 이미지·소재 방향**
6. **스크린도어 게재 규격과 글자 수 제한**
7. **경쟁 제품 비교 근거**: 없으면 이 줄은 지워도 됩니다
8. **채널당 안 개수**

`--target cc`라서 요청 설정(Request-config)은 만들지 않았습니다.
