# Elenchus patterns

Shapes, not scripts. Each one serves the current definition. KO/EN forms are given because most sessions run in one of the two.

## Forcing a definition

| User gives | Ask |
|---|---|
| An example ("짜장면 추천해 주는 거") | "그건 하나의 예네요. 그런 것들이 모두 X인 건 무엇 때문일까요?" / "That's one case. What makes all of them X?" |
| A list ("빠르고, 맛있고, 싸고…") | "그 셋이 다 있어야 X인가요, 하나만 있어도 X인가요?" |
| A synonym ("좋은 추천은 괜찮은 추천") | "'괜찮다'는 건 뭘 보고 알 수 있어요?" |
| "Depends" / "상황마다 달라" | "그 여러 상황에서 X라고 부르는 공통점이 하나라도 있나요?" |
| A refusal ("정의는 필요 없어") | "그럼 지금 만들려는 게 X인지 아닌지는 어떻게 알아볼 수 있어요?" |

## Premise questions (one per message, yes/no friendly)

- **Too broad:** "정의대로라면 [포함되는 이상한 사례]도 X인데, 그것도 X라고 할 수 있나요?" / "By that definition [odd case] counts as X. Is it?"
- **Too narrow:** "[분명 X인 사례]는 정의에 안 들어가는데, 그건 X가 아닌가요?"
- **Goal check:** "아까 [사용자가 말한 목표]를 원한다고 했죠. 이 정의대로 하면 그게 이뤄지나요?"
- **Consequence:** "X가 정말 그거라면, [따라 나오는 일]도 받아들여야 하나요?"
- **Hypothesis** (Meno 86e-87b), when "what is X" stalls: "X가 뭔지는 잠시 두고, X가 [조건]이라고 가정하면 무엇이 따라 나올까요?"

Agreed premises are numbered silently. Use only those numbers in Step 4.

## Laying out a contradiction (≤ 4 lines)

```
① <definition> (정의)
② <agreed premise> (동의)
③ <agreed premise, if needed> (동의)
그럼 ①과 ②는 함께 설 수 없어 보여요. 어디를 고칠까요?
```

In chat, render it as plain lines or a quote block, not a code block. The code block above only shows the shape.

## When the user pushes back

- "②는 그런 뜻이 아니었어" → "그럼 ②를 어떻게 고쳐 말할까요?" Restate it, get a "yes", and re-check whether the conflict still holds.
- "그건 논리 비약이야" → re-read the step. If they're right: "맞아요, 그 단계는 성립하지 않네요. 거둘게요." Then continue.
- "그냥 내 정의가 맞아" → "어떤 경우를 보면 그 정의가 틀렸다고 인정할 수 있을까요?" If nothing could, note that as a finding, not a strength.

## Noticing a birth

When a revision moves the concept, name the move in one line: "<old> → <new>". Moves usually go one of these ways:

- from a means to an end ("빠른 추천" → "고민할 시간을 줄여 주는 것")
- from one person to another ("내가 편한" → "팀이 같이 고르기 쉬운")
- from a feature to a condition ("무료" → "아무 준비물 없이 올 수 있는")

These moves are the brainstorm's output. A rewording that changes nothing is not a birth; say so.

## Signs of aporia

- The user's last two definitions have each fallen, and they have no third.
- The user says "모르겠다" or "생각해 봐야겠다" about X itself, not about a detail.
- Each new definition reintroduces a premise they already gave up.

Name it gently: "지금 우리는 X가 무엇인지 모른다는 걸 알게 된 것 같아요." Then go to the record.
