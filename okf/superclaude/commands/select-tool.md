# Select Tool

Intelligent MCP tool selection based on complexity scoring and operation analysis. Use ONLY when user explicitly types `/sc:select-tool` — meta-utility for analyzing which MCP fits given operation. Do NOT auto-trigger during normal tool selection — pick appropriate MCP directly from context.

Source of truth: `src/superclaude/commands/select-tool.md`.

Invoke with `/sc:select-tool`.
