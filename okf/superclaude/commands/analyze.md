# Analyze

Code analysis across quality, security, performance, architecture domains. Use when user types `/sc:analyze`, asks "audit", "review codebase for X", or names multiple analysis dimensions one request. Do NOT auto-trigger on reading single file, looking up symbol, or "what does this function do" — those direct reads, not multi-domain analysis.
