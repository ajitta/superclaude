# Spec Panel

Multi-expert spec review + improvement via renowned software engineering experts. Use when user types `/sc:spec-panel` or asks for multi-expert panel critique (Fowler, Beck, Martin, etc.) of software spec. Do NOT auto-trigger on routine spec read or single-reviewer feedback — those get direct review.

Source of truth: `src/superclaude/commands/spec-panel.md`.

Invoke with `/sc:spec-panel`.
