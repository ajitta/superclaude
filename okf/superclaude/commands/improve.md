# Improve

Apply systematic improvements to code quality, performance, and maintainability. Use when user types `/sc:improve` or asks for multi-file quality/perf/maintainability sweep with measurable targets. Do NOT auto-trigger on "improve this function", "rename this variable", or small single-file refactors — those direct edits.

Source of truth: `src/superclaude/commands/improve.md`.

Invoke with `/sc:improve`.
