# Brainstorm

Interactive requirements discovery thru Socratic dialogue + systematic exploration. Use when user types `/sc:brainstorm`, ask "spec out feature", "discover requirements", or call idea "vague" / "fuzzy". Do NOT auto-trigger on routine code questions, casual "what should we do about X" exploration, or single-answer factual queries — those get direct response, not discovery flow.

Source of truth: `src/superclaude/commands/brainstorm.md`.

Invoke with `/sc:brainstorm`.
