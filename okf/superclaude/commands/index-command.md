# Index

Generate comprehensive project documentation and knowledge base with intelligent organization. Use ONLY when user explicitly types `/sc:index` — generates multi-file project knowledge base under docs/reports/. Do NOT auto-trigger on "document this" or single-file documentation requests — use /sc:document or direct edits instead.
