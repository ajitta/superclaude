# Insight

Capture structured session insights to per-project JSONL for human + tool analysis. Use when user types `/sc:insight` (with optional --list/--query/--stats/--review) or explicitly asks to record an insight ("record this insight", "capture this as an insight"). NO auto-trigger on "let me note this" or general observation — insights = deliberate capture, no auto-snapshot.

Source of truth: `src/superclaude/commands/insight.md`.

Invoke with `/sc:insight`.
