# #212 refactor(config): unify settings loader

Merged 2026-10-01 by @dana · reviewed by @lee

Replaces the three settings readers (CLI flags, `tidepool.toml`, built-in defaults) with one `Settings` loader, so every command resolves settings the same way.

## Notes

- Keys are validated against the `Settings` schema. An unknown key is skipped with a debug-level log line (not shown at the default log level).
- `cache_dir` is gone; the loader reads `cache_path` instead. A config that still sets `cache_dir` loads without error, and the cache falls back to `/tmp/tidepool-cache`.
- CLI flags behave as before.

## Tests

- `tests/config/test_loader.py`: precedence (flag > file > default) for every key.
